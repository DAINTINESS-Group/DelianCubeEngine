# Setup Adult Dataset

## To setup adult in your MSQL Server:
1. Unzip the Adult_no_dublic.zip that contains the cleaned version of the data without duplicates.
2. Execute the schema dump file to create the schema.
3. Execute the data dump file to load the data.

## Given in this directory ready for use are: 
1. My SQL Server Connection Info (dbc.ini).
2. The cube adult_cube (adult.ini)

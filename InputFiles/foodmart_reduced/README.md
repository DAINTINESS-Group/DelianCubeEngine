## Setup Foodmart Reduced Dataset

## To setup foodmart reduced in your My SQL Server:
1. Move the data file to My SQL Server's Upload directory.
2. Execute the full dump file to create the schema and load the data (foodmart_schema.sql).

## Given in this directory ready for use are: 
1. My SQL Server Connection Info (dbc.ini).
2. The cube sales_cube (sales.ini)

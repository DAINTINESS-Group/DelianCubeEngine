## Setup pkdd99 Dataset

## To setup pkdd99 in your My SQL Server:
1. Execute pkdd99_schemaCreation.sql to load pkdd99 schema.
2. Execute pkdd99_fullDump.sql to load the data.

## Given in this directory ready for use are: 
1. My SQL Server Connection Info (dbc.ini).
2. The cube sales_cube (sales.ini)

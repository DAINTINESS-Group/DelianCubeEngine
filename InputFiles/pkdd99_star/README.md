## Setup pkdd99_star Dataset

## To setup pkdd99_star in your My SQL Server:
1. Execute pkdd99_star_schemaCreation.sql to load pkdd99 star schema.
2. Execute pkdd99_star_dataDump.sql to load the data.

## Given in this directory ready for use are: 
1. My SQL Server Connection Info (dbc.ini).
2. The cube sales_cube (sales.ini)
